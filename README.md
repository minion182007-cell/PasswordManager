# Password Manager

Консольный менеджер паролей на Python. Программа хранит пароли от сайтов в зашифрованном файле. Доступ к хранилищу защищён мастер-паролем.

## Возможности

- Создание хранилища с помощью `--init`.
- Открытие существующего хранилища с помощью `--unlock`.
- Генерация случайных паролей с помощью `--generate`.
- Добавление новых записей (сайт, логин, пароль).
- Просмотр списка сохранённых сайтов.
- Просмотр пароля с дополнительным подтверждением мастер-паролем.
- Удаление сохранённых записей.

## Требования

- Python 3.14.
- [uv](https://docs.astral.sh/uv/).

## Установка

Склонируйте репозиторий и перейдите в папку проекта. Затем установите зависимости:

```bash
uv sync
```

## Запуск

### Создание хранилища

Для создания нового хранилища выполните:

```bash
uv run python -m password_manager --init
```

Программа предложит ввести и подтвердить мастер-пароль.

### Вход в хранилище

Для открытия существующего хранилища выполните:

```bash
uv run python -m password_manager --unlock
```

После успешного ввода мастер-пароля откроется главное меню программы.

### Генерация пароля

Для генерации случайного пароля длиной 16 символов:

```bash
uv run python -m password_manager --generate
```

Чтобы указать собственную длину, используйте параметр `--length`:

```bash
uv run python -m password_manager --generate --length 24
```

Если запустить программу без аргументов, она выведет справку с доступными командами.

## Как работает шифрование

При создании хранилища генерируются две случайные соли:

- `master_salt` — используется для получения хеша мастер-пароля.
- `key_salt` — используется для получения ключа шифрования.

На основе мастер-пароля с помощью алгоритма PBKDF2 с 600 000 итераций вычисляются хеш и ключ шифрования.

Данные хранятся в формате JSON. Перед сохранением записи сериализуются и шифруются с помощью Fernet.

В файле `vault.json` находятся соли, хеш мастер-пароля и зашифрованные данные. Сам мастер-пароль и пароли от сайтов в открытом виде не сохраняются.

При входе программа проверяет введённый мастер-пароль. Если проверка проходит успешно, из него повторно формируется ключ шифрования и расшифровываются сохранённые записи.

Мастер-пароль нигде не хранится.

## Структура проекта

```text
password_manager/
    __init__.py        # Делает папку Python-пакетом
    __main__.py        # Точка входа для python -m password_manager
    cli.py             # Аргументы командной строки и меню
    core.py            # Класс PasswordManager, работа с хранилищем
    crypto_utils.py    # Хеширование, шифрование и генерация паролей

tests/
    test_core.py       # Тесты класса PasswordManager
    test_generator.py  # Тесты генератора паролей
```

Модули разделены по назначению:

- `crypto_utils.py` отвечает за криптографические операции и не работает с файлами.
- `core.py` отвечает за хранилище и записи, не взаимодействуя напрямую с пользователем.
- `cli.py` отвечает за ввод, вывод, аргументы командной строки и меню.

Такое разделение упрощает тестирование и дальнейшее развитие проекта.

## Формат хранилища

По умолчанию данные сохраняются в файл `vault.json`.

Пример его структуры:

```json
{
  "master_salt": "base64...",
  "master_hash": "base64...",
  "key_salt": "base64...",
  "data": "gAAAAA..."
}
```

Описание полей:

- `master_salt` — соль для хеширования мастер-пароля.
- `master_hash` — сохранённый хеш мастер-пароля.
- `key_salt` — соль для получения ключа шифрования.
- `data` — зашифрованные записи.

После расшифровки поле `data` содержит словарь следующего вида:

```json
{
  "github.com": {
    "login": "ivan",
    "password": "example_password"
  }
}
```

## Главное меню

После входа в хранилище доступны следующие действия:

| Команда | Действие |
|---|---|
| `1` | Добавить новую запись |
| `2` | Посмотреть список сохранённых сайтов |
| `3` | Показать пароль после подтверждения мастер-паролем |
| `4` | Удалить запись |
| `0` | Выйти из программы |

## Коды завершения

| Код | Значение |
|---|---|
| `0` | Успешное выполнение |
| `1` | Ошибка выполнения: неверный пароль, отсутствие или существование хранилища, исчерпание попыток входа или неверная длина генерируемого пароля |
| `2` | Ошибка аргументов командной строки, например одновременное использование `--init` и `--unlock` |
| `130` | Прерывание программы с помощью `Ctrl+C` |

## Ограничения

- Используется одно хранилище с именем `vault.json` и путём по умолчанию.
- Отсутствуют функции импорта и экспорта записей.
- Нет возможности изменить мастер-пароль.
- Графический интерфейс не предусмотрен.
- При потере мастер-пароля восстановить сохранённые данные невозможно.

## Безопасность

Файл `vault.json` содержит зашифрованные пользовательские данные, поэтому его не следует добавлять в публичный репозиторий.

Для защиты пользовательских данных файл хранилища и локальные файлы окружения должны быть добавлены в `.gitignore`.

Рекомендуется использовать надёжный мастер-пароль и не передавать его другим людям.
